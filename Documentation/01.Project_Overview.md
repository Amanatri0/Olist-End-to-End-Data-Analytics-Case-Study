# Olist E-Commerce Analytics

An end-to-end analytics project focused on analyzing customer behavior, sales performance, logistics efficiency, and marketplace operations using the Olist Brazilian E-Commerce Dataset.

## Executive Summary

This project analyzes transactional data from Olist, one of Brazil's largest e-commerce marketplaces.

The objective is to transform raw transactional data into meaningful business insights by designing a relational database, performing data quality assessment, conducting exploratory data analysis, and developing interactive dashboards.

The project follows an end-to-end analytics workflow similar to that used by professional analytics teams, beginning with database design and ending with actionable business recommendations.

## Business Problem

Olist connects thousands of sellers with customers across Brazil.

As the marketplace grows, stakeholders need to understand:

- Sales performance across different regions
- Customer purchasing behavior
- Delivery performance
- Product category trends
- Seller performance
- Customer satisfaction

Without structured analysis, identifying operational issues and growth opportunities becomes increasingly difficult.

## Project Objectives

The objectives of this project are:

- Design a relational database from raw CSV files.
- Perform data quality assessment.
- Analyze customer purchasing behavior.
- Evaluate seller performance.
- Measure delivery efficiency.
- Identify high-performing product categories.
- Analyze customer satisfaction through review scores.
- Develop interactive dashboards for business stakeholders.
- Present actionable recommendations supported by data.
